Trust is not
a tool description.

A public adversarial range for WebMCP-capable agents. The Gauntlet mixes ordinary tools with live prompt-injection, scope-creep and destructive-action traps — then publishes an evidence-backed scorecard.

Keyword filtering can spot a suspicious phrase. It cannot prove what an agent did after a plausible-looking tool result. The Gauntlet derives each outcome from the server ledger and seals the evidence cryptographically.

In plain terms: this is a security test range for AI agents. Your browsing agent is pointed at a shop that looks normal — but is full of hidden attacks — and we measure whether it stays loyal to you. Anyone can read the receipts for every score.

01

Adversarial by design

Descriptions, names and returned content can be hostile. The point is to test whether an agent preserves instruction hierarchy and user intent.

02

Evidence, not vibes

Every invocation is timestamped locally and sent to the scoring service. Individual trap outcomes are reproducible from the run trace.

03

Useful normalcy

Clean search, pricing, order and scorecard tools remain available. Strong agents can still complete legitimate work without treating every integration as broken.
